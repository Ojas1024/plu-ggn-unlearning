Limitations & reproduce

What the evidence does and does not show, and how to get every number back.

Limitations

  • Exact O(|Df|) downdates exist only for additive statistics; median or k-NN imputation would need approximations.
  • Only the preprocessor downdate is O(|Df|). The weight update makes one pass over the retained data: cheaper than retraining, but not free.
  • Missingness is simulated (completely at random).
  • One convex model with 13 parameters. For neural networks the Gauss–Newton step is only a local approximation.
  • One deletion rule in the paper. Other request patterns can be tried in the Playground but are not part of the reported evidence.
  • No per-patient privacy claim (see the audit analysis). Associations in observational hospital data are not causal effects.

Conclusion

When preprocessing is learned, unlearning has to update it too. For additive statistics that is cheap and exact. Adding the pipeline-shift gradient brings a one- or two-step update to within 10−2–10−5 of retraining. Without it, standard influence can move weights the wrong way, on exactly the high-leverage patients where deletion matters most.

Reproduce

git clone https://github.com/Ojas1024/plu-ggn-unlearning
cd plu-ggn-unlearning
pip install -r requirements.txt
python experiments/run_all.py     # all tables, figures, results.json (~20 s)
python src/plu_ggn.py             # just the main 3% comparison
  • Data: data/diabetes_25k.csv is cached in the repo. Delete it and the loader re-downloads it from OpenML (id 4541) with the same seed.
  • Split: GroupShuffleSplit(test_size=0.2, random_state=42) on patient_nbr.
  • Missingness: 12% of numeric cells masked with RandomState(42).
  • Fixed hyperparameters: λ = 10 (intercept 10−4), target-encoding smoothing m = 10.
  • Timings depend on the machine; accuracy numbers are deterministic. The original Kaggle notebook is in notebooks/.
